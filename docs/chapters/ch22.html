22  Nonlinear methods for biology

Many biological processes and phenomena are related in ways that do not form straight lines. What this really means is that rates of change are not constant. While linear models and the assumption of linearity are powerful ways to think about and analyze biological phenomena, they are not always appropriate. This module will introduce you to some ways of exploring situations where one quantity does not scale as a constant proportion of another.

So far we have learned about a wide variety of linear models, generalized and otherwise. Linear models predict some response variable \(y\) as a linear function of one or more predictor variables \(x\). One key feature of linear functions is that their slopes are constant. Each model coefficient describes the change in \(Y\) per unit change in \(X\). As we saw in Section 16.2.1, many functions that appear nonlinear at first can be made linear by transforming one or both of \(Y\) and \(X\).

22.1 Curve terminology

Straight lines are easy to describe. They have an angle relative to the axes (the slope) and one point where they intersect the y-axis: the intercept. Both of these characteristics are parameters of a function. A function is an operation that assigns each value in one set to exactly one value in another set. In this case, the function assigns each value in \(x\) to one and only one expected \(y\) value (remember, a statistical model has a deterministic part that produces the expected value, and a stochastic part for describing the residual variation).

22.1.1 Domain and codomain

Because a statistical model describes a function, the straight line acquires two more characteristics. The domain of the function is the set of inputs accepted by the function. The codomain is the set of outputs (some older books call this the range, but that term is now considered ambiguous).

Figure 22.3 shows some data and a linear function fitted to them. The domain of the fitted function is the interval between the smallest and largest \(x\) values. Its codomain is the interval that spans all of the observed \(y\) values.

Mathematically, the domain and codomain of a linear function are the real numbers, often abbreviated \(\mathbb{R}\). But we’re not doing math, we are doing statistics. The linear model that we fit to the data is only applicable within the set of \(x\) and \(y\) values used to fit it. Using the model to make predictions outside the domain of its data, or extrapolation, can be fraught with peril.

22.1.2 Slopes and tangent lines

Nonlinear models, by definition, do not have a constant slope like a linear model does. Usually the slope of the function at any point is a function of the \(x\) value. Some of them have parameters that we refer to as a slope or growth rate, but these are really inputs to a function that determines the actual slope.

The function below shows a nonlinear curve \(f\left(x\right)\) and its tangent line at \(x=7\). The tangent line is a line that intersects a function at exactly one point and has the same slope as the function at that point. The slope of the tangent line is calculated as the first derivative of the function at that \(x\) value.

22.1.3 Concavity

Nonlinear curves are also described by their concavity. A function is said to be concave up wherever its tangent line is below the graph of the function, and concave down when the tangent line lies above it. Remember the mnemonic, “up cup, down frown”. The concavity of a function is related to its second derivative, or the rate of change in the slope at any given point.

In Figure 22.5 below, the left panel shows a linear function \(y=2+0.75x\) and its constant slope of 0.75. The right panel shows a nonlinear curve whose slope changes with \(x\) (see Figure 22.4), and the tangent lines at \(x=2.5\) and \(x=7\). At the first point, the tangent line is below the function, so the function is concave up. At the second, the tangent line is above the function, so the function is concave down there. Note that the slopes of both tangent lines are positive.

The second derivative that defines concavity is the rate of change in the slope: \(dy/dx/dx\), or \(dy/dx^2\). Figure 22.6 below shows a function which has a positive slope everywhere, but whose slope is decreasing. So, the function is concave down. Its first derivative is always positive, because the rate of change in \(y\) with respect to \(x\) is always positive, but that rate of change decreases as \(x\) gets larger.

22.1.4 Inflection points and midpoints

Some functions can change concavity over their domain. The \(x\) value at which they change concavity is called the inflection point. The function below has an inflection point near 3.6 where it changes from concave up (dark grey region) to concave down (light grey region). Some nonlinear functions have an inflection point as a parameter (Table 22.2).

When a function has a well-defined lower and upper value, we can define a midpoint: the \(x\) coordinate at which \(f\left(x\right)\) is equal to half of the distance between the minimum and the maximum. If the minimum is 0, then this is the \(x\) such that \(f\left(x\right)=\max{\left(f\left(x\right)\right)}/2\).

Note that although an inflection point and a midpoint may appear similar, they are not the same: an inflection point is where the concavity changes, and a midpoint is where the function has gone halfway from its minimum to its maximum. These can coincide, as in the standard logistic function in the left panel below, but more often they do not.

22.2 Common nonlinear functions

22.2.1 The Michaelis-Menten function

The Michaelis-Menten function is a nonlinear model that is usually used to describe processes that grow and approach an asymptote. One of the classic applications is modeling the relationship between biochemical reaction rates and substrate concentrations. The Michaelis-Menten equation takes the general form

\[Y=\frac{aX}{b+X}\]

where a and b are constants. It has a fixed lower bound at 0 and no inflection point.

  • \(a\) is the asymptote: the maximum \(y\) value that is approached but never reached.
  • \(b\) is the Michaelis constant. It represents the \(x\) value at which \(Y = a/2\). Interestingly, for any proportion of the form \(c/(c+1)\), where c is a positive integer, the X value where \(y=(c/(c+1))a\) is \(cb\). For example, the X value when \(y=(3/4)a\) is \(3b\).
x <- seq(0, 10, length=100)
a <- c(4, 6, 8, 10)
b <- 3

par(mfrow=c(2,1), mar=c(5,5,1,3), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable")
for(i in 1:length(a)){
    iy <- (a[i]*x)/(b+x)
    points(x, iy, type="l", lwd=3)
    text(max(x)+0.25, max(iy),
         paste("a =", a[i]),
         adj=0, cex=1.1)
}#i

a <- 5
b <- c(1, 3, 5, 7)
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, 5))
for(i in 1:length(b)){
    iy <- (a*x)/(b[i]+x)
    points(x, iy, type="l", lwd=3)
    text(max(x)+0.25, max(iy),
         paste("b =", b[i]),
         adj=0, cex=1.1)
}#i

The Michaelis-Menten curve goes by many names. In enzyme kinetics and biochemistry, it is called the Michaelis-Menten curve. Biologists also sometimes call it the Monod function, the Holling type II functional response, or the Beverton-Holt model. This diversity of application speaks to the generality of this function. The original definition predicted a reaction rate. However, Michaelis-Menten curves can also be used to model other phenomena. For example, Kunz et al. (2019) and Green et al. (2020) used Michaelis-Menten curves to model the effectiveness of biodiversity monitoring programs, using the asymptote term as an estimate of the maximum number of species likely to be detected.

22.2.2 Gompertz functions

The Gompertz curve is a sigmoid (s-shaped) growth curve frequently used to describe biological growth. It can be written in several ways. You can use whichever form you want, but you need to be explicit about what you did. In both cases, all parameters must be positive.

22.2.2.1 Gompertz curve form 1

The most common form of the Gompertz curve is a double exponential:

\[\mathcal{f}\left(x\right)={ae}^{-be^{-cx}}\]

where \(a\) is the upper asymptote, \(b\) defines the x coordinate of the inflection point at \(\log{\left(b\right)/c}\), and \(c\) is a growth rate. The inflection point occurs at

\[x_{inflection}=\frac{\log\left(b\right)}{c}\]

and at that point,

\[y_{inflection}=\mathcal{f}\left(x_{inflection}\right)=\frac{a}{e}\approx0.368\]

22.2.2.2 Gompertz curve form 2

Another form of the Gompertz function looks like this:

\[\mathcal{f}\left(x\right)=ae^{-bc^x}\]

This version is used in the R SSgompertz function that we’ll see later. It is actually equivalent to the first version because of the identity

\[e^{-cx}=\left(e^{-c}\right)^x\]

Start with form 1 and substitute:

\[\mathcal{f}\left(x\right)={ae}^{-be^{-cx}}\]

\[\mathcal{f}\left(x\right)={ae}^{-b\left(e^{-c}\right)^x}\]

The second form replaces \(e^{-c}\) with a new constant, which the SSgompertz documentation calls b3 (with the \(b\) term from form 1 being renamed b2):

\[\mathcal{f}\left(x\right)={ae}^{-b_2\left(b_3\right)^x}\]

So, the two forms seen here produce the same curve, just in a slightly different way:

Below is an illustration of the classic Gompertz curve with different parameters.

22.2.3 The von Bertalanffy growth function

Like the Gompertz curve, the von Bertalanffy growth curve describes size increasing and approaching an asymptote. Unlike the Gompertz curve, the von Bertalanffy model is not sigmoid, but rather has a decreasing slope. That is, it is always concave down whereas the the Gompertz model can have a concave up portion, a concave down portion, and an inflection point in between.

The von Bertalanffy model is commonly written as:

\[f\left(x\right)=L_\infty\left(1-e^{-k\left(x-t_0\right)}\right)\]

where \(L_{\infty}\) is the asymptotic length as \(t\) approaches \(\infty\), \(k\) is a growth rate parameter, and \(t_0\) is the theoretical time at which \(\mathcal{f}\left(t\right)=0\). \(L_{\infty}\) and \(k\) must be positive, and \(t_0\) must be negative. The von Bertalanffy model is commonly used to describe animal growth, but in principle it could be used for any situation where its parameters make sense. The same function is also sometimes called the monomolecular curve. Like the Gompertz curve, the von Bertalanffy model has several forms. The form given above is the most common.

x <- seq(0, 50, length=100)
Linf <- c(50, 100, 150, 200)
K <- 0.05
T0 <- -1

C <- c(0.25, 0.5, 1, 2)

         adj=0, cex=1.2)
}#i

22.2.4 Logistic and log-logistic functions

A logistic curve is one that takes the form

\[f\left(x\right)=\frac{L}{1+e^{-b\left(x-x_0\right)}}\]

where \(L\) is the supremum (upper asymptote), \(b\) is a growth rate, and \(x_0\) is the midpoint (\(x\) value where \(f\left(x\right)=L/2\)). Logistic functions are sigmoid, with a lower limit of 0 as x tends to \(-\infty\) and upper limit of \(L\) as x approaches \(+\infty\). The standard logistic function with \(L=1\), \(b=1\) and \(x_0=0\) is

\[f\left(x\right)=\frac{1}{1+e^{-x}}\]

which you may recognize as the inverse of the logit function, given by the R function plogis().

x <- seq(-6, 6, length=100)
y <- plogis(x)

par(mfrow=c(1,1), mar=c(5,5,1,3), 
    xpd=NA, bty="n")
plot(x, y, type="l", lwd=3, xlab="x variable",
     ylab="y variable", ylim=c(0, 1))
segments(0, 0, 0, 0.5, lty=2, lwd=2, col="red")
segments(0, 0.5, -6, 0.5, lty=2, lwd=2, col="red")

The logistic function can be generalized by adding parameters to specify the upper and lower asymptotes or other features. These versions are called log-logistic functions because they use the logarithm of \(x\), not \(x\) itself. We will examine four versions:

  • the two-parameter log-logistic (2pl): uses a midpoint (\(g\)) and a slope parameter (\(b\)), with lower and upper asymptotes fixed at 0 and 1, respectively.
  • the three-parameter log-logistic (3pl): extends the two-parameter log-logistic model with a new term \(d\) to define an upper asymptote other than 1.
  • the four-parameter log-logistic (4pl): extends the three-parameter log-logistic model with a new term \(c\) to define a lower asymptote other than 0.
  • the five-parameter log-logistic (5pl): extends the four-parameter log-logistic model with a new term \(h\) to alter the shape of the curve.

In practical terms:

  • the four-parameter model is just the special case of the five-parameter model with \(h=1\)
  • the three-parameter model is just the special case of the four-parameter model with \(c=0\)
  • the two-parameter model is the special case of the three-parameter model with \(d=1\).
NoteA note on parameter names

Textbooks and software packages differ a bit in the way that they label the parameters of the models in this section. In this guide I have tried to be as consistent as possible, at least within each group like the log-logistic or the Weibull families. The letters or symbols are not important–their positions in the equations are. In general, I try to avoid using \(e\) and \(f\) as names of parameters because in most contexts \(e\) is the symbol for Euler’s number and \(f\) is often used to label functions (e.g., \(f\left(x\right)=\dots\)).

22.2.4.1 Two-parameter log-logistic

The two-parameter log-logistic function is like the standard logistic function (Figure 22.17), but with parameters \(b\) for the slope and \(g\) for the midpoint. It is given by:

\[f\left(x\right)=\frac{1}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

Notice that here \(x\) is part of a difference in the exponent, which has the effect of moving the curve left and right.

The \(b\) parameter defines the curve’s growth rate. Counter intuitively, the function increases when \(b<0\), and decreases when \(b>0\). Greater magnitudes of \(b\), regardless of sign, make for steeper curves.

x <- seq(0.1, 10, length=100)
B <- -1*c(0.5, 1, 2, 4, 8)
G <- 5

cols <- c("#e41a1c", "#377eb8", "#4daf4a","#984ea3", "#ff7f00")
par(mfrow=c(1,1), mar=c(5,5,1,4), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, 1))
for(i in 1:length(B)){
    iy <- 1/(1+exp(B[i]*(log(x)-log(G))))
    points(x, iy, type="l", lwd=3,
           lty=i, col=cols[i])
    text(max(x)+0.2, max(iy),
         bquote(italic(b)==.(B[i])),
         adj=0, cex=1.2,
         col=cols[i])
}#i

Positive \(b\) cause the function to decrease:

22.2.4.2 Three-parameter log-logistic

The three-parameter log-logistic generalizes the two-parameter log-logistic by adding a term for either the upper or lower asymptote. Either the lower limit is fixed at 0 and the upper limit is the parameter \(d\), or the upper limit can be fixed at 1 and the lower limit is the parameter \(c\). The former version, with lower limit fixed at 0, is probably more common so we’ll focus on that one.

Lower limit fixed at 0:

The most commonly encountered version of the three-parameter log-logistic model has the lower limit fixed at 0 and the upper limit as a parameter \(d\):

\[f\left(x\right)=\frac{d}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

where \(d\) is the upper asymptote, \(b\) is a growth rate, and \(g\) is the inflection point.

Tipe is not always e

In the R documentation for log-logistic functions, especially in package drc, the midpoint parameter that we call \(g\) here is often referred to as \(e\). I find this incredibly unhelpful, so I use a different letter instead. Using \(e\) for something other than Euler’s constant is like using \(\pi\) to stand for something other than the ratio of a circle’s circumference to its diameter…which people also do sometimes. Read the documentation!

Upper limit fixed at 1:

The less commonly encountered version of the three-parameter log-logistic function has the upper limit fixed at 1 and the lower limit as a parameter \(c\):

\[f\left(x\right)=c+\frac{1-c}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

Here is an illustration of the fixed-lower version of the three-parameter log-logistic function with differing upper asymptotes:

x <- seq(0.1, 10, length=100)
B <- -5
G <- 5
D <- c(4, 8, 12, 16)

22.2.4.3 Four-parameter log-logistic

If we take the three-parameter log-logistic, and allow both the upper and lower asymptotes to vary, we get the four parameter log-logistic. It has terms for the lower asymptote (\(c\)), upper asymptote (\(d\)), midpoint (\(g\)), and growth rate (\(b\)):

\[f\left(x\right)=c+\frac{d-c}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

As in all of these log-logistic curves, the \(g\) parameter is particularly useful because it can be interpreted as the ED50, or the dose producing a response halfway between \(c\) and \(d\). When \(c=0\) and \(d=1\), this is literally a response of 50% or 0.5; otherwise the \(g\) parameter relates to a response midway between \(c\) and \(d\). Again, note that what we are calling \(g\) is referred to in the drc documentation as e.

22.2.4.4 Five-parameter log-logistic

The most flexible version of the log-logistic model has 5 parameters: a lower asymptote \(c\), an upper asymptote \(d\), a growth rate \(b\), a midpoint \(g\), and a shape parameter \(h\). When \(h\neq1\), the function is asymmetric about \(g\). When \(h=1\), the model reduces to the four-parameter log-logistic. We obtain the five-parameter model by adding an exponent \(h\) to the entire denominator of the four-parameter model :

\[f\left(x\right)=c+\frac{d-c}{\left(1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}\right)^h}\]

The exponent \(h\) allows the curve to be asymmetric about the midpoint \(g\), when \(h\neq1\). For an intuition about what \(h\) does, imagine that the curve is a rubber or plastic rod bent into an s-shape–the shape of the log-logistic curve. If you grab the rod at the midpoint \(g\) and twist clockwise, the curve will decrease left of \(g\) and increase right of \(g\). That is like decreaseing \(h\) from 1 towards 0. If you twist counter-clockwise, the curve will decrease. This is like increasing \(h\) from 1. Note that we need to adjust \(g\) as a function of \(h\) to keep the midpoint the same.

x <- seq(1, 500, length=100)
B <- -2
C <- 0
D <- 10
G <- 150

       legend=c(expression(italic(h)==1),

                expression(italic(h)==0.1)),

       bty="n", cex=1.2)

The reason we had to adjust the midpoint to see the asymmetry wrought by \(h\) is that making the curve asymmetrical has the side effect of changing the slope at \(x=g\) (everywhere, really).

This is because at \(x=g\), \(\log{\left(x\right)}-\log{\left(x\right)}=0\), so the exponent equals \(b\left(0\right)=0\), so the exponential term \(e^{0}=1\), so:

\[f\left(x\right)=c+\frac{d-c}{\left(1+e^{b\left(\log{\left(x\right)}-\log{\left(x\right)}\right)}\right)^h}=c+\frac{d-c}{\left(1+1\right)^h}\]

When \(h=1\), this is halfway between the asymptotes. But when \(h<1\), \(2^h<2\), so \(f\left(g\right)>c+\left(d-c\right)/2\) (the function is greater than the halfway point). 22.2.5 Weibull curves

22.2.5.1 Derivation

The Weibull function describes a sigmoid curve between a lower and upper asymptote. So, it can behave much like a Gompertz or log-logistic curve, and is suitable in many of the same situations. Like the log-logistic group above, there are several versions of the Weibull function that with different numbers of parameters. Each additional parameter in the function allows another aspect of the curve to vary.

Like the log-logistic function, the Weibull function is derived from a probability distribution. The Weibull distribution is a continuous probability distribution often used for waiting times, similar to the gamma distribution. The cumulative distribution function (CDF) of the Weibull distribution for non-negative values is

\[F_{Weibull}\left(x\right)=1-e^{-\left(x/\lambda\right)^k}\]

where \(k\) and \(\lambda\) are the parameters of the distribution (shape and scale, respectively). We can take advantage of some exponent and logarithm rules to rewrite the Weibull CDF as a double exponential:

\[ \begin{aligned} F(x) &= 1-e^{-(x/\lambda)^k} && \qquad \text{Start with Weibull CDF}\\ F(x) &= 1-e^{-\left(\frac{x^k}{\lambda^k}\right)} && \qquad \text{Power of a quotient}\\ F(x) &= 1-e^{-e^{\log\left(\frac{x^k}{\lambda^k}\right)}} && \qquad \text{Definition of logarithm}\\ F(x) &= 1-e^{-e^{\log(x^k)-\log(\lambda^k)}} && \qquad \text{Logarithm of a quotient}\\ F(x) &= 1-e^{-e^{k\log(x)-k\log(\lambda)}} && \qquad \text{Power rule for logarithms}\\ F(x) &= 1-e^{-e^{k(\log(x)-\log(\lambda))}} && \qquad \text{Factor out } k \end{aligned} \]

This double exponential form of the Weibull CDF is sometimes called the “Type 2” Weibull function, including in the R package drc. The complement of the double exponential form of the Weibull CDF is the “Type 1” Weibull curve:

\[\text{Weibull curve}=e^{-e^{k\left(\log\left(x\right)-\log\left(\lambda\right)\right)}}\]

This version of the Weibull function has two parameters, and so it is called the two-parameter Weibull function. Like the two-parameter log-logistic, a three- and four-parameter version of the function can be defined by adding additional parameters to define an upper asymptote other than 1 (Section 22.2.5.3) and a lower asymptote other than 0 (Section 22.2.5.4). Unlike the log-logistic and the Gompertz functions, the Weibull function does not have a midpoint or inflection point as a parameter but it can be derived from parameters.

22.2.5.2 Two-parameter Weibull function

The two-parameter Weibull type 1 model is the basic Weibull function we derived in the previous section. We will use \(b\) instead of \(k\) for the shape parameter, and \(c\) instead of \(\lambda\) for the scale constant. It is given by

\[f\left(x\right)=e^{-e^{b\left(\log\left(x\right)-\log\left(c\right)\right)}}\] where \(b\) is the shape parameter and \(c\) is the scale parameter. This function has a lower asymptote at 0 and upper asymptote at 1. The figure below shows how the curve changes shape with different \(b\) parameters.

22.2.5.3 Three-parameter Weibull function

The three-parameter Weibull curve adds a parameter \(d\) to the two-parameter Weibull model to specify the upper asymptote:

\[f\left(x\right)=de^{-e^{b\left(\log{\left(x\right)}-\log{\left(c\right)}\right)}}\]

Varying the shape \(b\) or the scale \(c\) has the same effect as it does in the two-parameter Weibull (Figure 22.27, Figure 22.28), just with the upper asymptote shifted to \(d\).

22.2.5.4 Four-parameter Weibull function

Finally, the four-parameter Weibull curve adds one more parameter, \(a\), which can specify a lower asymptote other than 0:

\[f\left(x\right)=a+\left(d-a\right)e^{-e^{b\left(\log\left(x\right)-\log\left(c\right)\right)}}\] where \(b\) is the shape, \(c\) is the scale, \(d\) is the upper asymptote, and \(a\) is the lower asymptote.

22.2.6 Nonlinear functions summary

We have seen 5 types of nonlinear functions commonly used for biological data: the Michaelis-Menten, the Gompertz, the von Bertalanffy, the (log)-logistic, and the Weibull curves. Each of these can take on many shapes, and choosing which one to use to model your data requires both statistical know-how and, more importantly, biological judgement.

The functions that we explore can take on many shapes. So, the most important question is not, “Which curve looks the most like my scatterplot?” but rather “Which curve has parameters that make biological sense for my question?”. These curves are useful because they are defined in terms that describe biology quite well: minimum and maximum values, inflection points, midpoints, and growth rates.

22.3 Nonlinear least squares with nls()

The basic nonlinear least squares (NLS) model has some parts in common with the basic linear regression model (LM). In the state-space GLM notation, we can see that the relationship between the observed \(y\) variable and the expected value \(\mu\) is the same as in the LM. However, the relationship between the expected value and the predictor variables is not the same.

\[y\sim \mathcal{Normal}\left(E\left(y\right),\sigma^2_{res}\right)\]

\[E\left(y\right)=\mathcal{f}\left(x\right)\]

where \(\mathcal{f}\left(x\right)\) is a nonlinear function of \(x\). In the NLS model, as with LM, the response variable \(y\) is drawn from a normal distribution with mean \(\mu\) and residual variance \(\sigma^2_{res}\). Unlike LM, in NLS the function for the expected value \(f\left(x\right)\) can be any number of functions.

The equations above show an important assumption of NLS: the errors are normally distributed with constant variance. If you need a another response distribution, then there are generalized nonlinear models that extend nonlinear models the way that GLM extends LM.

Unlike LM, where it is relatively straightforward to solve some linear algebra problems and get stable parameter estimates, in NLS the parameters must be approximated by searching the parameter space (i.e., set of possible values) for parameter values that minimize the sum of squared residuals. The methods for computing these estimates are extremely complicated and sensitive to starting inputs, and we won’t go into them here. Bolker (2008) gives an overview of some of these methods. The practical upshot for the average user is that starting values for the model must be supplied.

22.3.4 Confidence intervals for nonlinear models

Unlike lm() and glm(), there is no base option for generating confidence intervals on an nls() model. Instead, we need to use package propagate.

library(propagate)

Set up a series of \(x\) values and calculate a confidence interval. Note that if you use a self-start version of a model, you may get strange confidence intervals because propagate won’t be able to represent the model correctly. So, you may want to fit the selfStart version to get parameter estimates, then refit by specifying the model explicitly, using the parameter estimates from the selfStart() version as starting values. You can then use the estimates from the explicit version to generate confidence intervals.

n <- 10
px <- seq(min(dx$totalLength, na.rm=TRUE),
          max(dx$totalLength, na.rm=TRUE), length=n)
prx <- data.frame(totalLength=px)

# notice we use mod2, the explicitly coded model
# and not the selfStart version (which is mod1)
py <- predictNLS(mod2,
                 newdata=prx,
                 interval="confidence",
                 nsim=1e4) # default is 1e6; this is for speed

The predictNLS function actually estimates 3 versions of the confidence interval. The first two are by the Delta method, while the third is a Monte Carlo approximation. Usually the 3 estimates don’t disagree too much, and you usually can pick any of them. If one of them looks odd, go with one of the others.

# NOTE: this example uses R version 4.6.1 and
#       propagate version 1.2-0. The structure
#       of the predictNLS output is a bit 
#       different than previous versions of 
#       propagate (e.g., 1.0-7).
# first order delta approximation
prx$mn <- py$summary[,1] # mean.1
prx$lo <- py$summary[,5] # 2.5% (first one)
prx$up <- py$summary[,6] # 97.5% (first one)

par(mar=c(5,5,1,1))
plot(dx$totalLength, dx$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)")
points(px, prx$mn, type="l", lwd=3, col="red")
points(px, prx$lo, type="l", lwd=2, col="red", lty=2)
points(px, prx$up, type="l", lwd=2, col="red", lty=2)

22.3.5 Factors and interactions in nonlinear models

Unlike lm() and glm(), adding factors and interactions in nls() takes a bit of coding. The trick is to write the model function explicitly with group-specific parameters, and include a multiplier to multiply those parameters by 0 for observations where they aren’t needed. Let’s fit a different curve for ear length in two families, Cricetidae and Muridae. Download the taxonomic dataset and use it to filter the individual measurements dataset.

tax <- read.csv("data-neon-taxa.csv")
use.vars <- c("abb", "totalLength", "earLength")
dx2 <- dx[complete.cases(dx[,use.vars]),]


dx2$family <- tax$family[match(dx2$abb,tax$abb)]

# cricetid species
cri <- tax$abb[which(tax$family=="Cricetidae")]
# murid species
mur <- tax$abb[which(tax$family=="Muridae")]

dx2 <- dx2[which(dx2$abb %in% c(cri, mur)),]


# colors and shapes
cols <- c("#4F94CD4D", "tomato3")
names(cols) <- c("Cricetidae", "Muridae" )
pchs <- c(0, 1)
names(pchs) <- names(cols)
dx2$col <- cols[dx2$family]
dx2$pch <- pchs[dx2$family]

par(mar=c(5,5,1,1))
plot(dx2$totalLength, dx2$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)",
     col=dx2$col, pch=dx2$pch)
legend("topleft", legend=names(cols),
       pch=pchs, col=cols,
       cex=1.2,bty="n")

Add an indicator variable for each group, for each level of our factor. The value is 1 for observations in the group, and 0 otherwise.

dx2$cr <- ifelse(dx2$family=="Cricetidae", 1, 0)
dx2$mu <- ifelse(dx2$family=="Muridae", 1, 0)

Now construct the model.

mod4 <- nls(earLength~cr*((a.cr*totalLength)/(b.cr+totalLength))+
                      mu*((a.mu*totalLength)/(b.mu+totalLength)),
            data=dx2,
            start=list(a.cr=50, b.cr=180, a.mu=20, b.mu=180))
summary(mod4)

22.3.6 Significance and nonsignificance in nonlinear models

The p-values in an nls() summary test whether each estimated parameter differs from zero, using an approximation based on the parameter’s standard error. These tests are not necessarily meaningful for nonlinear models, especially when parameters have biological constraints or zero represents a degenerate model. For example, a nonsignificant asymptote term \(a\) in a Michaelis-Menten model or log-logistic model (\(d\)) may be mathematically valid, but biologically nonsensical. Instead of relying on p-values, focus primarily on parameter estimates, their confidence intervals, and how well the model describes the observed relationship.
