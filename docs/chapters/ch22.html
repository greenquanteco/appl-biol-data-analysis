22  Nonlinear methods for biology

Many biological processes and phenomena are related in ways that do not form straight lines. What this really means is that rates of change are not constant. While linear models and the assumption of linearity are powerful ways to think about and analyze biological phenomena, they are not always appropriate. This module will introduce you to some ways of exploring situations where one quantity does not scale as a constant proportion of another.

So far we have learned about a wide variety of linear models, generalized and otherwise. Linear models predict some response variable \(y\) as a linear function of one or more predictor variables \(x\). One key feature of linear functions is that their slopes are constant. Each model coefficient describes the change in \(Y\) per unit change in \(X\). As we saw in Section 16.2.1, many functions that appear nonlinear at first can be made linear by transforming one or both of \(Y\) and \(X\).

But some functions cannot be transformed to linearity. Consider the function below.

22.1 Common nonlinear functions

22.1.1 Michaelis-Menten curves

The Michaelis-Menten function is a nonlinear model that is usually used to describe processes that grow and approach an asymptote. One of the classic applications is modeling the relationship between biochemical reaction rates and substrate concentrations. The Michaelis-Menten equation takes the general form

\[Y=\frac{aX}{b+X}\]

where a and b are constants.

  • \(a\) is the asymptote: the maximum \(y\) value that is approached but never reached.
  • \(b\) is the Michaelis constant. It represents the \(x\) value at which \(Y = a/2\). Interestingly, for any proportion of the form \(c/(c+1)\), where c is a positive integer, the X value where \(y=(c/(c+1))a\) is \(cb\). For example, the X value when \(y=(3/4)a\) is \(3b\).
x <- seq(0, 10, length=100)
a <- c(4, 6, 8, 10)
b <- 3

par(mfrow=c(2,1), mar=c(5,5,1,3), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable")
for(i in 1:length(a)){
    iy <- (a[i]*x)/(b+x)
    points(x, iy, type="l", lwd=3)
    text(max(x)+0.25, max(iy),
         paste("a =", a[i]),
         adj=0, cex=1.1)
}#i

a <- 5
b <- c(1, 3, 5, 7)
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, 5))
for(i in 1:length(b)){
    iy <- (a*x)/(b[i]+x)
    points(x, iy, type="l", lwd=3)
    text(max(x)+0.25, max(iy),
         paste("b =", b[i]),
         adj=0, cex=1.1)
}#i

The Michaelis-Menten curve goes by many names. In enzyme kinetics and biochemistry, it is called the Michaelis-Menten curve. Biologists also sometimes call it the Monod function, the Holling type II functional response, or the Beverton-Holt model. This diversity of application speaks to the generality of this function. The original definition predicted a reaction rate. However, Michaelis-Menten curves can also be used to model other phenomena. For example, Kunz et al. (2019) and Green et al. (2020) used Michaelis-Menten curves to model the effectiveness of biodiversity monitoring programs, using the asymptote term as an estimate of the maximum number of species likely to be detected.

22.1.2 Gompertz curve

The Gompertz curve is a sigmoid (s-shaped) growth curve frequently used to describe biological growth. It can be written in several ways. You can use whichever form you want, but you need to be explicit about what you did. Most people use the second of the two forms presented below. In both cases, all parameters must be positive.

22.1.2.1 Gompertz curve form 1

The most common form of the Gompertz curve is a double exponential:

\[\mathcal{f}\left(t\right)={ae}^{-be^{-ct}}\]

where \(a\) is the upper asymptote, \(b\) moves the curve along the time axis \(t\), and \(c\) is a growth rate. The inflection point occurs at

\[t_{inflection}=\frac{\log\left(b\right)}{c}\]

and at that point,

\[y_{inflection}=\mathcal{f}\left(t_{inflection}\right)=\frac{a}{e}\approx0.368\]

22.1.2.2 Gompertz curve form 2

Another form of the Gompertz function looks like this:

\[\mathcal{f}\left(t\right)=ae^{-bc^t}\]

This version is used in the R SSgompertz function that we’ll see later. It is actually equivalent to the first version because of the identity

\[e^{-cx}=\left(e^{-c}\right)^x\]

Start with form 1 and substitute:

\[\mathcal{f}\left(t\right)={ae}^{-be^{-ct}}\]

\[\mathcal{f}\left(t\right)={ae}^{-b\left(e^{-c}\right)^t}\]

The second form replaces \(e^{-c}\) with a new constant, which the SSgompertz documentation calls b3 (with the \(b\) term from form 1 being renamed b2):

\[\mathcal{f}\left(t\right)={ae}^{-b_2\left(b_3\right)^t}\]

So, the two forms seen here produce the same curve, just in a slightly different way:

Below is an illustration of the classic Gompertz curve with different parameters.

x <- seq(0, 10, length=100)

22.1.3 von Bertalanffy

Like the Gompertz curve, the von Bertalanffy growth curve describes size increasing and approaching an asymptote. Unlike the Gompertz curve, the von Bertalanffy model is not sigmoid, but rather has a decreasing slope. That is, it is always concave down whereas the the Gompertz model has a concave up portion, a concave down portion, and an inflection point in between.

The von Bertalanffy model is commonly written as:

\[f\left(x\right)=L_\infty\left(1-e^{-k\left(x-t_0\right)}\right)\]

where \(L_{\infty}\) is the asymptotic length as \(t\) approaches \(\infty\), \(k\) is a growth rate parameter, and \(t_0\) is the theoretical time at which \(\mathcal{f}\left(t\right)=0\). \(L_{\infty}\) and \(k\) must be positive, and \(t_0\) must be negative. The von Bertalanffy model is commonly used to describe animal growth, but in principle it could be used for any situation where its parameters make sense. The same function is also sometimes called the monomolecular curve. Like the Gompertz curve, the von Bertalanffy model has several forms. The form given above is the most common.

x <- seq(0, 50, length=100)
Linf <- c(50, 100, 150, 200)
K <- 0.05
T0 <- -1

C <- c(0.25, 0.5, 1, 2)
cols <- c("#e41a1c", "#377eb8", "#4daf4a","#984ea3")
par(mfrow=c(1,1), mar=c(5,5,1,4), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, max(Linf)))
for(i in 1:length(Linf)){
    iy <- Linf[i]*(1-exp((-1*K)*(x-T0)))
    points(x, iy, type="l", lwd=3,
           lty=i, col=cols[i])
    text(max(x)+1, max(iy),
         bquote(italic(L)[infinity]==.(Linf[i])),
         adj=0, cex=1.2)
}#i

    xpd=NA, bty="n")

     ylab="y variable", ylim=c(0, max(Linf)))

22.1.4 Logistic curves

A logistic curve is one that takes the form

\[f\left(x\right)=\frac{L}{1+e^{-k\left(x-x_0\right)}}\]

where \(L\) is the supremum (upper asymptote), \(k\) is a growth rate, and \(x_0\) is the midpoint (\(x\) value where \(f\left(x\right)=L/2\)). Logistic functions are sigmoid, with a lower limit of 0 as x tends to \(-\infty\) and \(L\) as x approaches \(+\infty\). The standard logistic function with \(L=1\), \(k=1\) and \(x_0=0\) is

\[f\left(x\right)=\frac{1}{1+e^{-x}}\]

which you may recognize as the inverse of the logit function, given by the R function plogis().

x <- seq(-6, 6, length=100)
y <- plogis(x)

par(mfrow=c(1,1), mar=c(5,5,1,3), 
    xpd=NA, bty="n")
plot(x, y, type="l", lwd=3, xlab="x variable",
     ylab="y variable", ylim=c(0, 1))
segments(0, 0, 0, 0.5, lty=2, lwd=2, col="red")
segments(0, 0.5, -6, 0.5, lty=2, lwd=2, col="red")

22.1.4.1 Three parameter log-logistic

The logistic function can be generalized by adding parameters to specify the upper and lower asymptotes or other features. One common version is the three parameter log-logistic, available in the R package drc. This model is called the “log-logistic” because it uses the logarithm of \(x\), not \(x\) itself. The three parameter log-logistic comes in several flavors:

Lower limit fixed at 0:

\[f\left(x\right)=\frac{d}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

where \(d\) is the upper asymptote, \(b\) is a growth rate, and \(g\) is the inflection point. Notice that here \(x\) is part of a difference in the exponent, which has the effect of moving the curve left and right.

Tipe is not always e

In the R documentation for log-logistic functions, especially in package drc, the midpoint parameter that we call \(g\) here is often referred to as \(e\). I find this incredibly unhelpful, so I use a different letter instead. Using \(e\) for something other than Euler’s constant is like using \(\pi\) to stand for something other than the ratio of a circle’s circumference to its diameter…which people also do sometimes. Read the documentation!

Another version of the three-parameter log-logistic function has the upper limit fixed at 1:

\[f\left(x\right)=c+\frac{1-c}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

where \(c\) is the lower asymptote.

22.1.4.2 Four parameter log-logistic

There is also a four parameter logistic:

\[f\left(x\right)=c+\frac{d-c}{1+e^{b\left(\log{\left(x\right)}-\log{\left(g\right)}\right)}}\]

where \(d\) is the upper asymptote, \(c\) is the lower asymptote, \(b\) is a growth constant, and \(g\) is the inflection point.

In all of these log-logistic curves, the \(g\) parameter is particularly useful because it can be interpreted as the ED50, or the dose producing a response halfway between \(c\) and \(d\). When \(c=0\) and \(d=1\), this is literally a response of 50% or 0.5; otherwise the \(g\) parameter relates to a response midway between \(c\) and \(d\). Again, note that what we are calling \(g\) is referred to in the drc documentation as e.

Here is an illustration of the four-parameter log-logistic curve with varying \(b\) parameters:

x <- seq(0.1, 10, length=100)
B <- -1*c(0.5, 1, 2, 4, 8)
C <- 0
D <- 10
G <- 5

cols <- c("#e41a1c", "#377eb8", "#4daf4a","#984ea3", "#ff7f00")
par(mfrow=c(1,1), mar=c(5,5,1,4), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, max(D)))
for(i in 1:length(B)){
    iy <- C+(D-C)/(1+exp(B[i]*(log(x)-log(G))))
    points(x, iy, type="l", lwd=3,
           lty=i, col=cols[i])
    text(max(x)+0.2, max(iy),
         bquote(italic(b)==.(B[i])),
         adj=0, cex=1.2,
         col=cols[i])
}#i
x <- seq(0.1, 10, length=100)
B <- -8
C <- 0
D <- 10
G <- c(2, 4, 6, 8)

cols <- c("#e41a1c", "#377eb8", "#4daf4a","#984ea3")
par(mfrow=c(1,1), mar=c(5,5,1,4), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, max(D)))
for(i in 1:length(G)){
    iy <- C+(D-C)/(1+exp(B*(log(x)-log(G[i]))))
    points(x, iy, type="l", lwd=3,
           lty=i, col=cols[i])
}#i
legend("bottomright",
       legend=c(expression(italic(g)==2),
                expression(italic(g)==4),
                expression(italic(g)==6),
                expression(italic(g)==8)),
       lty=1:3, lwd=3, col=cols,
       bty="n", cex=1.2)
for(i in 1:length(G)){
    segments(0, D/2, G[i], D/2, lty=2)
    segments(G[i], 0, G[i], D/2, lty=2)
}

22.1.5 Weibull curves

The Weibull curve is really a family of functions with a sigmoid shape between a lower and upper asymptote. So, they can behave much like a Gompertz or log-logistic curve, and are suitable in many of the same situations. The Weibull curves differ in their numbers of parameters.

The two-parameter Weibull type 1 model is

\[f\left(x\right)=e^{-e^{b\left(\log\left(x\right)-\log\left(c\right)\right)}}\] where \(c\) is the inflection point and \(b\) is a growth constant. This function has a lower asymptote at 0 and upper asymptote at 1.

The three-parameter Weibull curve adds a parameter \(d\) to the two-parameter Weibull model to specify the upper asymptote:

\[f\left(x\right)=de^{-e^{b\left(\log{\left(x\right)}-\log{\left(c\right)}\right)}}\]

Finally, the four-parameter Weibull curve adds one more parameter, \(a\), which can specify a lower asymptotes other than 0:

\[f\left(x\right)=a+\left(d-a\right)e^{-e^{b\left(\log\left(x\right)-\log\left(c\right)\right)}}\] where \(d\) is the upper asymptote and \(a\) is the lower asymptote. Unlike the log-logistic functions, none of the parameters is directly interpretable as the ED50. The Weibull curve is essentially a Gompertz-like sigmoid double exponential function applied to the logarithm of dose. Weibull curves are typically asymmetric.

When \(b\) is negative, the Weibull curve increases:

x <- seq(0.1, 10, length=100)
A <- 0
B <- -1*c(1, 2, 4, 8)
C <- 4
D <- 10


cols <- c("#e41a1c", "#377eb8", "#4daf4a","#984ea3")
par(mfrow=c(1,1), mar=c(5,5,1,4), 
    xpd=NA, bty="n")
plot(x, x, type="n", xlab="x variable",
     ylab="y variable", ylim=c(0, max(D)))
off <- c(0, 0, 0, 0.2)
for(i in 1:length(B)){
    iy <- A+(D-A)*exp(-1*exp(B[i]*(log(x)-log(C))))
    points(x, iy, type="l", lwd=3,
           lty=i, col=cols[i])
    text(max(x)+0.2, max(iy)+off[i],
         bquote(italic(b)==.(B[i])),
         adj=0, cex=1.2,
         col=cols[i])
}#i

When \(b\) is positive, then the Weibull curve decreases:

22.1.6 Growth curves summary

We have seen 4 types of nonlinear functions commonly used for biological data: the Michaelis-Menten, the Gompertz, the von Bertalanffy, the (log)-logistic, and the Weibull curves. Each of these can take on many shapes, and choosing which one to use to model your data requires both statistical know-how and, more importantly, biological judgement. The most important question is often not, “Which curve looks the most like my scatterplot?” but rather “Which curve has parameters that make biological sense for my question?”. These curves are useful because they are defined in terms that describe biology quite well: minimum and maximum values, inflection points, midpoints, and growth rates.

22.2 Nonlinear least squares with nls()

The basic nonlinear least squares (NLS) model has some parts in common with the basic linear regression model (LM). In the state-space GLM notation, we can see that the relationship between the observed \(y\) variable and the expected value \(\mu\) is the same as in the LM. However, the relationship between the expected value and the predictor variables is not the same.

\[y\sim \mathcal{Normal}\left(E\left(y\right),\sigma^2_{res}\right)\]

\[E\left(y\right)=\mathcal{f}\left(x\right)\]

where \(\mathcal{f}\left(x\right)\) is a nonlinear function of \(x\). In the NLS model, as with LM, the response variable \(y\) is drawn from a normal distribution with mean \(\mu\) and residual variance \(\sigma^2_{res}\). Unlike LM, in NLS the function for the expected value \(f\left(x\right)\) can be any number of functions.

The equations above show an important assumption of NLS: the errors are normally distributed with constant variance. If you need a another response distribution, then there are generalized nonlinear models that extend nonlinear models the way that GLM extends LM.

Unlike LM, where it is relatively straightforward to solve some linear algebra problems and get stable parameter estimates, in NLS the parameters must be approximated by searching the parameter space (i.e., set of possible values) for parameter values that minimize the sum of squared residuals. The methods for computing these estimates are extremely complicated and sensitive to starting inputs, and we won’t go into them here. Bolker (2008) gives an overview of some of these methods. The practical upshot for the average user is that starting values for the model must be supplied.

22.2.1 Fitting the model with self start functions

Let’s take a look at the NEON data. Download the individual measurement dataset and load it into R.

dx <- read.csv("data-neon-ind-meas.csv")

We will try a nonlinear model of ear length as a function of body length.

par(mar=c(5,5,1,1))
plot(dx$totalLength, dx$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)")

Models in nls() require starting values to prevent the algorithm from going too far afield. Finding appropriate values can be tricky. Fortunately, there are “self starting” models for many common functions (see ?selfStart for a list).

We will try a self-starting Michaelis-Menten function (SSmicmen) based not on any real biological basis, but rather the apparent shape of the curve.

mod1 <- nls(earLength~SSmicmen(totalLength,a,b), data=dx)

22.2.2 Fitting the model without self start functions

Sometimes we need to fit a model without a self starting function. This might be because we are fitting a model for which there is no self start function. Or, we need to feed an output to propagate. Either way, without a self starting function you will need to supply starting values for each parameter. This is usually done in a named list. Below, we refit the ear length vs. body length relationship using the estimates from the self start model as starting values.

mod2 <- nls(earLength~(a*totalLength)/(b+totalLength),
            data=dx,
            start=list(a=30, b=180))

If we don’t have a previous model fit to start with, we need to be clever. The best approach is to think about what the parameters really mean, and where they show up on the plot, and deduce from there. For example, for the ear length plot we might guess that the asymptote is no more than about 40 or 50. That is our starting guess for the \(a\) parameter. Then, we just need to eyeball where the curve reaches half of \(a\). Maybe 200 or so. That is our starting guess for the \(b\) parameter. Let’s try it.

mod3 <- nls(earLength~(a*totalLength)/(b+totalLength),

22.2.3 Plotting a nonlinear curve

We can get a trendline in the usual way, by setting up a series of x values and calculating the predicted value at those values.

n <- 100
px <- seq(min(dx$totalLength, na.rm=TRUE),
          max(dx$totalLength, na.rm=TRUE), length=n)
prx <- data.frame(totalLength=px)
py <- predict(mod1, newdata=prx)


par(mar=c(5,5,1,1))
plot(dx$totalLength, dx$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)")
points(px, py, type="l", lwd=4, col="red")

22.2.4 Confidence intervals for nonlinear models

Unlike lm() and glm(), there is no base option for generating confidence intervals on an nls() model. Instead, we need to use package propagate.

library(propagate)

Set up a series of \(x\) values and calculate a confidence interval. Note that if you use a self-start version of a model, you may get strange confidence intervals because propagate won’t be able to represent the model correctly. So, you may need to fit the selfStart version, then refit by specifying the model explicitly, then using the explicit version to generate confidence intervals.

n <- 10
px <- seq(min(dx$totalLength, na.rm=TRUE),
          max(dx$totalLength, na.rm=TRUE), length=n)
prx <- data.frame(totalLength=px)
py <- predictNLS(mod2,
                 newdata=prx,
                 interval="confidence",
                 nsim=1e4) # default is 1e6; this is for speed

The predictNLS function actually estimates 3 versions of the confidence interval. The first two are by the Delta method, while the third is a Monte Carlo approximation. Usually the 3 estimates don’t disagree too much, and you usually can pick any of them. If one of them looks odd, go with one of the others.

# 2026-10-26
# different versions of propagate 
# use different column names!
if("Prop.Mean.1" %in% names(py$summary)){
    # first order delta approximation
    prx$mn <- py$summary$Prop.Mean.1 
    prx$lo <- py$summary$'Prop.2.5%'
    prx$up <- py$summary$'Prop.97.5%'   
} 
if("mean.1" %in% names(py$summary)){
    # first order delta approximation
    prx$mn <- py$summary$mean.1 
    prx$lo <- py$summary$'2.5%'
    prx$up <- py$summary$'97.5%'
}


par(mar=c(5,5,1,1))
plot(dx$totalLength, dx$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)")
points(px, prx$mn, type="l", lwd=3, col="red")
points(px, prx$lo, type="l", lwd=2, col="red", lty=2)
points(px, prx$up, type="l", lwd=2, col="red", lty=2)

22.2.5 Factors and interactions in nonlinear models

Unlike lm() and glm(), adding factors and interactions in nls() takes a bit of coding. The trick is to write the model function explicitly with group-specific parameters, and include a multiplier to multiply those parameters by 0 for observations where they aren’t needed. Let’s fit a different curve for ear length in two families, Cricetidae and Muridae. Download the taxonomic dataset and use it to filter the individual measurements dataset.

tax <- read.csv("data-neon-taxa.csv")
use.vars <- c("abb", "totalLength", "earLength")
dx2 <- dx[complete.cases(dx[,use.vars]),]


dx2$family <- tax$family[match(dx2$abb,tax$abb)]

# cricetid species
cri <- tax$abb[which(tax$family=="Cricetidae")]
# murid species
mur <- tax$abb[which(tax$family=="Muridae")]

dx2 <- dx2[which(dx2$abb %in% c(cri, mur)),]


# colors and shapes
cols <- c("#4F94CD4D", "tomato3")
names(cols) <- c("Cricetidae", "Muridae" )
pchs <- c(0, 1)
names(pchs) <- names(cols)
dx2$col <- cols[dx2$family]
dx2$pch <- pchs[dx2$family]

par(mar=c(5,5,1,1))
plot(dx2$totalLength, dx2$earLength,
     xlab="Total length (mm)",
     ylab="Ear length (mm)",
     col=dx2$col, pch=dx2$pch)
legend("topleft", legend=names(cols),
       pch=pchs, col=cols,
       cex=1.2,bty="n")

Add an indicator variable for each group, for each level of our factor. The value is 1 for observations in the group, and 0 otherwise.

dx2$cr <- ifelse(dx2$family=="Cricetidae", 1, 0)
dx2$mu <- ifelse(dx2$family=="Muridae", 1, 0)

Now construct the model.

mod3 <- nls(earLength~cr*((a.cr*totalLength)/(b.cr+totalLength))+
                      mu*((a.mu*totalLength)/(b.mu+totalLength)),
            data=dx2,
            start=list(a.cr=50, b.cr=180, a.mu=20, b.mu=180))
summary(mod3)

           length=100)
