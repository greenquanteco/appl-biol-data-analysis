23  Random effects and mixed models

23.1 Introduction

So far, the linear models (LMs) and generalized linear models (GLMs) we have studied have included two components:

  1. A systematic component (or deterministic component), which describes how the expected value of the response variable depends on the predictor variables.
  2. A stochastic component, which describes random variation in the response variable around its expected value.

For example, consider a linear regression describing the relationship between body mass and metabolic rate:

\[ Y_i=\beta_0+\beta_1X_i+\varepsilon_i \]

The systematic component is \(\beta_0+\beta_1X_i\), which describes the expected metabolic rate for an animal of a given body mass. The stochastic component is \(\varepsilon_i\), which describes the variation in metabolic rate that the systematic component does not explain. In an ordinary linear model, we generally assume that the residuals are independent and identically distributed, with mean zero and variance \(\sigma^2_{res}\). Another way to state that i.i.d. assumption is that the residual variation is unstructured.

But what if some of that unexplained variation has an identifiable structure?

Suppose our animals were measured in several different laboratories. Measurements from the same laboratory might be more similar to each other than measurements from different laboratories, perhaps because of differences in equipment, experimental protocols, or environmental conditions. This inter-laboratory variation has a structure, but it is not a structure that we as researchers are interested in. We want to account for it, certainly, but we are not interested in these laboratories themselves as experimental units.

Our original linear model does not explicitly account for this source of variation. We could add laboratory as a categorical predictor, as we did in analysis of covariance (ANCOVA). If we assume that the metabolic rate measurements were differently calibrated in each laboratory, that model would look like:

\[ Y_i=\beta_0+\beta_{1,lab_i}+\beta_2X_i+\varepsilon_i \]

This model adds a term \(\beta_{1,lab}\) that captures the lab-specific effect. This term functions as an extra intercept, so we could also have written:

$$ Y_i=_{0,lab_i}+_1X_i+_i

$$

Where the lab determines the intercept directly. In either case, we are fitting the effect of lab as we do any other model parameter, such as the slope for body mass. The fitted lab-specific intercepts describe differences among the particular laboratories that made the measurements, potentially reflecting differences in equipment, experimental conditions, or other factors.

It is worth asking the question: “Do we care about the differences between Laboratories A, B, and C specifically, or do we primarily want to account for variation among laboratories?” The former goal, estimating differences among these specific laboratories, helps us understand the data in front of us. The second goal, accounting for variation among laboratories more generally, could allow us to generalize our results beyond the particular laboratories in our dataset.

Fitting laboratory-specific parameters—that is, including laboratory in the deterministic part of the model—accomplishes the first goal. To accomplish the second, we can instead model variation among laboratories as an additional stochastic component. This allows us to estimate the relationship between body mass and metabolic rate while accounting for differences among laboratories, and to characterize how much that relationship might vary in other laboratories.

If we assign the random variation between labs to a new, second stochastic part of the model, we define a random effect of laboratory. A random effect in a statistical model is a parameter that varies between groups according to some probability distribution. In our example, we can include a random intercept to account for variation in measured values between laboratories:

\[ Y_i=\beta_{0,lab_i}+\beta_1X_i+\varepsilon_i \]

\[ \beta_{0,lab}\sim\text{Normal}\left(\mu_{\beta_0},\sigma^2_{\beta_0}\right) \]

The intercepts \(\beta_0\) vary between labs as \(\beta_{0,lab}\), and those intercepts come from a normal distribution with mean \(\mu_{\beta_0}\) and variance \(\sigma^2_{\beta_0}\). Another option would be to fit a model with random slopes, where the slopes vary according to a normal distribution with mean \(\mu_{\beta_1}\) and variance \(\sigma^2_{\beta_1}\).

\[ Y_i=\beta_0+\beta_{1,lab_i}X_i+\varepsilon_i \]

\[ \beta_{1,lab}\sim\text{Normal}\left(\mu_{\beta_1},\sigma^2_{\beta_1}\right) \]

or even a model with a random intercept and random slope for lab:

\[ Y_i=\beta_{0,lab}+\beta_{1,lab_i}X_i+\varepsilon_i \]

\[ \beta_{0,lab}\sim\text{Normal}\left(\mu_{\beta_0},\sigma^2_{\beta_0}\right)\text{; }\beta_{1,lab}\sim\text{Normal}\left(\mu_{\beta_1},\sigma^2_{\beta_1}\right) \]

Group-level effects that vary according to a distribution are random effects. The other kind of effect, which you are used to seeing, are fixed effects. Fixed effects can be thought of as “global effects” that apply across all groups (in the dataset or not) and independent of group-level effects. A model that includes both fixed effects and random effects is a mixed effects model.

23.1.1 Putting the random in random effect

You may have noticed that the random effects we defined above all followed normal distributions. At this point in the course, after seeing the modules on GLMs, you might wonder why we don’t use other distributions to describe random effects.

Well, I can’t find a good answer for that. There is no mathematical reason we couldn’t use something like a gamma distribution for our random effects. The use of the normal is largely for convenience.

In the effects parameterization of the linear mixed effects model below, the random effect follows a normal distribution with a mean of 0. The normal is convenient here because it is symmetrical about 0, and so we don’t assume any skewness. The normal distribution is also well-justified by the central limit theorem. In our example, laboratory differences might reflect many small, approximately independent influences: equipment calibration, technician behavior, temperature, experimental procedures, and so forth. If the laboratory effect is approximately the sum of many such influences, a normal distribution is a reasonable approximation. The final, and probably biggest reason for assuming normally-distributed random effects is that the normal distribution is computationally very convenient.

There are legitimate biological or statistical reasons why a non-normal distribution for random effects might be appropriate. For example, a gamma or lognormal distribution might be appropriate for effects which are strictly positive, when effects are multiplicative in nature, or when random effects might be highly right-skewed (many small values, few large values).

Random effects are usually assumed to follow a normal distribution with a mean of zero and an unknown variance (in effects parameterization). The mean is zero because the random effects represent deviations from the population-level relationship, while the variance describes how much groups differ from one another. The normal distribution is convenient because it accommodates both positive and negative deviations and is relatively easy to work with mathematically. Other distributions are possible, but fitting models with non-normal random effects often requires more specialized methods. In means parameterization, where group-level intercepts or slopes are defined directly, the random distribution has a mean of \(\mu_{\beta}\), not 0.

I’m not aware of a method for fitting a model with non-normal random effects in R, but coding such a model is trivial in JAGS. Be aware that you will have to work very hard to justify such effects to Reviewer 2.

23.2 Linear mixed effects models (LMM)

23.2.1 Definition

The linear mixed effects model extends the linear model to include random effects. If we start with a basic linear regression model with one predictor \(x\), we can define three versions: a random intercept model, a random slope model, and a full random model.

23.2.1.1 Random intercept model

This model has a random effect of group on the intercept. The first part is the response distribution that relates the expected value \(\mu_i\) to the observed values in \(y_i\).

\[y_i\sim\text{Normal}\left(\mu_i,\sigma^2_{res}\right)\]

The systematic part of the model, containing the expression for \(\mu_i\), includes an effect \(\gamma_{group_i}\) which is the effect on the intercept associated with the group of observation \(i\). The form below is the effects parameterization, which expresses the random effect as how it changes the intercept. In other words, the realized intercept in group A will be \(\beta_0+\gamma_A\)

\[\mu_i=\beta_0+\beta_1x_i+\gamma_{group_i};\text{ }\gamma_{group}\sim \text{Normal}\left(0,\sigma^2_{\gamma_{group}}\right)\]

The group-level effects on the intercept follow a normal distribution with mean \(0\) and variance \(\sigma^2_{\gamma_{group}}\).

Because the global intercept \(\beta_0\) and the random intercept are both scalars and occur as a sum in the model, many people omit the \(\gamma\) term (“gamma”) and simplify this to:

\[\mu_i=\beta_{0,group_i}+\beta_1x_i\]

\[\beta_{0,group}\sim \text{Normal}\left(\mu_{\beta_{0,group}},\sigma^2_{\beta_{0,group}}\right)\]

The first version keeps the global intercept and the group-level effect on the intercept separate, while the second version fits a group-level intercept directly.

23.2.1.2 Random intercept model

This model has a random effect of group on the slope It has the same response distribution step as the random intercept model above. The systematic part is a bit different: the random effect of group changes the slope of \(x\), not the intercept.

\[\mu_i=\beta_0+\left(\beta_1+\gamma_{group_i}\right)x_i\]

\[\gamma_{group}\sim\text{Normal}\left(\mu_{\gamma_{group}},\sigma^2_{\gamma_{group}}\right)\]

Just as with the random intercept model, the random slope model can be simplified so as to specify a group-level slope directly:

\[\mu_i=\beta_0+\beta_{1,group_i}x_i\]

\[\beta_{1,group}\sim\text{Normal}\left(\mu_{\beta_{1,group}},\sigma^2_{\beta_{1,group}}\right)\]

23.2.1.3 Random intercept and slope model

The full random model has a random intercept and a random slope. We get this model by combining the random intercept model and the random slope model:

\[\mu_i=\beta_{0,group_i}+\beta_{1,group_i}x_i\]

\[\beta_{0,group}\sim \text{Normal}\left(\mu_{\beta_{0,group}},\sigma^2_{\beta_{0,group}}\right)\]

\[\beta_{1,group}\sim\text{Normal}\left(\mu_{\beta_{1,group}},\sigma^2_{\beta_{1,group}}\right)\]

23.2.2 Example with NEON data

Let’s explore a linear mixed effects model using the NEON data. If you haven’t already, download the individual measurements dataset and the site metadata dataset.

dat <- read.csv("data-neon-ind-meas.csv")
met <- read.csv("data-neon-metadata-site.csv")

We are going to test for sexual dimorphism in body mass among white-footed mice (Peromyscus leucopus). We will also need to control for possible habitat differences.

Let’s filter and join the data first:

# filter to Perleu
dat <- dat[dat$abb=="Perleu",]
# drop missing body mass
dat <- dat[!is.na(dat$weight),]
# pull site out of tag id
dat$site <- sapply(strsplit(dat$tagID, "_"), "[", 2)

# only need these columns
use.cols <- c("site", "sex", "weight")
dx <- dat[,use.cols]

# merge to site descriptors
dx <- merge(dx, met, by="site")

# remove animals with unknown sex
dx <- dx[dx$sex %in% c("female", "male"),]

# remove wildly unrealistic body masses
dx <- dx[dx$weight >= 10 & dx$weight <= 30,]

We can check a boxplot of female vs. male body mass. It looks like any effect will be small.

boxplot(weight~sex, data=dx)

What about potential habitat differences?

par(mar=c(4, 10, 1, 1), las=1)
boxplot(weight~habitat, data=dx, horizontal = TRUE)

There is a lot of variability, but there might be some differences in body mass between the habitats.

We will fit the model two ways: as a linear model (two-way ANOVA) and as a linear mixed effects model. Each habitat type is represented by several sites. We want to isolate the effect of habitat while accounting for other differences between the sites. The table below shows that deciduous forest and grasslands are each represented by more than 1 site. If we included a habitat represented by only one site, then any apparent effect of that habitat would actually be confounded with that site.
