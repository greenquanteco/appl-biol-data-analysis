23  Random effects and mixed models

23.1 Introduction

So far, the linear models (LMs) and generalized linear models (GLMs) we have studied have included two components:

  1. A systematic component (or deterministic component), which describes how the expected value of the response variable depends on the predictor variables.
  2. A stochastic component, which describes random variation in the response variable around its expected value.

For example, consider a linear regression describing the relationship between body mass and metabolic rate:

\[ Y_i=\beta_0+\beta_1X_i+\varepsilon_i \]

The systematic component is \(\beta_0+\beta_1X_i\), which describes the expected metabolic rate for an animal of a given body mass. The stochastic component is \(\varepsilon_i\), which describes the variation in metabolic rate that the systematic component does not explain. In an ordinary linear model, we generally assume that the residuals are independent and identically distributed, with mean zero and variance \(\sigma^2_{res}\). Another way to state that i.i.d. assumption is that the residual variation is unstructured.

But what if some of that unexplained variation has an identifiable structure?

Suppose our animals were measured in several different laboratories. Measurements from the same laboratory might be more similar to each other than measurements from different laboratories, perhaps because of differences in equipment, experimental protocols, or environmental conditions. This inter-laboratory variation has a structure, but it is not a structure that we as researchers are interested in. We want to account for it, certainly, but we are not interested in these laboratories themselves as experimental units.

Our original linear model does not explicitly account for this source of variation. We could add laboratory as a categorical predictor, as we did in analysis of covariance (ANCOVA). If we assume that the metabolic rate measurements were differently calibrated in each laboratory, that model would look like:

\[ Y_i=\beta_0+\beta_{1,lab_i}+\beta_2X_i+\varepsilon_i \]

This model adds a term \(\beta_{1,lab}\) that captures the lab-specific effect. This term functions as an extra intercept, so we could also have written:

$$ Y_i=_{0,lab_i}+_1X_i+_i

$$

Where the lab determines the intercept directly. In either case, we are fitting the effect of lab as we do any other model parameter, such as the slope for body mass. The fitted lab-specific intercepts describe differences among the particular laboratories that made the measurements, potentially reflecting differences in equipment, experimental conditions, or other factors.

It is worth asking the question: “Do we care about the differences between Laboratories A, B, and C specifically, or do we primarily want to account for variation among laboratories?” The former goal, estimating differences among these specific laboratories, helps us understand the data in front of us. The second goal, accounting for variation among laboratories more generally, could allow us to generalize our results beyond the particular laboratories in our dataset.

Fitting laboratory-specific parameters—that is, including laboratory in the deterministic part of the model—accomplishes the first goal. To accomplish the second, we can instead model variation among laboratories as an additional stochastic component. This allows us to estimate the relationship between body mass and metabolic rate while accounting for differences among laboratories, and to characterize how much that relationship might vary in other laboratories.

If we assign the random variation between labs to a new, second stochastic part of the model, we define a random effect of laboratory. A random effect in a statistical model is a parameter that varies between groups according to some probability distribution. In our example, we can include a random intercept to account for variation in measured values between laboratories:

\[ Y_i=\beta_{0,lab_i}+\beta_1X_i+\varepsilon_i \]

\[ \beta_{0,lab}\sim\text{Normal}\left(\mu_{\beta_0},\sigma^2_{\beta_0}\right) \]

The intercepts \(\beta_0\) vary between labs as \(\beta_{0,lab}\), and those intercepts come from a normal distribution with mean \(\mu_{\beta_0}\) and variance \(\sigma^2_{\beta_0}\). Another option would be to fit a model with random slopes, where the slopes vary according to a normal distribution with mean \(\mu_{\beta_1}\) and variance \(\sigma^2_{\beta_1}\).

\[ Y_i=\beta_0+\beta_{1,lab_i}X_i+\varepsilon_i \]

\[ \beta_{1,lab}\sim\text{Normal}\left(\mu_{\beta_1},\sigma^2_{\beta_1}\right) \]

or even a model with a random intercept and random slope for lab:

\[ Y_i=\beta_{0,lab}+\beta_{1,lab_i}X_i+\varepsilon_i \]

\[ \beta_{0,lab}\sim\text{Normal}\left(\mu_{\beta_0},\sigma^2_{\beta_0}\right)\text{; }\beta_{1,lab}\sim\text{Normal}\left(\mu_{\beta_1},\sigma^2_{\beta_1}\right) \]

Group-level effects that vary according to a distribution are random effects. The other kind of effect, which you are used to seeing, are fixed effects. Fixed effects can be thought of as “global effects” that apply across all groups (in the dataset or not) and independent of group-level effects. A model that includes both fixed effects and random effects is a mixed effects model.

23.1.1 Putting the random in random effect

You may have noticed that the random effects we defined above all followed normal distributions. At this point in the course, after seeing the modules on GLMs, you might wonder why we don’t use other distributions to describe random effects.

Well, I can’t find a good answer for that. There is no mathematical reason we couldn’t use something like a gamma distribution for our random effects. The use of the normal is largely for convenience.

In the effects parameterization of the linear mixed effects model below, the random effect follows a normal distribution with a mean of 0. The normal is convenient here because it is symmetrical about 0, and so we don’t assume any skewness. The normal distribution is also well-justified by the central limit theorem. In our example, laboratory differences might reflect many small, approximately independent influences: equipment calibration, technician behavior, temperature, experimental procedures, and so forth. If the laboratory effect is approximately the sum of many such influences, a normal distribution is a reasonable approximation. The final, and probably biggest reason for assuming normally-distributed random effects is that the normal distribution is computationally very convenient.

There are legitimate biological or statistical reasons why a non-normal distribution for random effects might be appropriate. For example, a gamma or lognormal distribution might be appropriate for effects which are strictly positive, when effects are multiplicative in nature, or when random effects might be highly right-skewed (many small values, few large values).

Random effects are usually assumed to follow a normal distribution with a mean of zero and an unknown variance (in effects parameterization). The mean is zero because the random effects represent deviations from the population-level relationship, while the variance describes how much groups differ from one another. The normal distribution is convenient because it accommodates both positive and negative deviations and is relatively easy to work with mathematically. Other distributions are possible, but fitting models with non-normal random effects often requires more specialized methods. In means parameterization, where group-level intercepts or slopes are defined directly, the random distribution has a mean of \(\mu_{\beta}\), not 0.

I’m not aware of a method for fitting a model with non-normal random effects in R, but coding such a model is trivial in JAGS. Be aware that you will have to work very hard to justify such effects to Reviewer 2.

23.2 Linear mixed effects models (LMM)

23.2.1 Definition

The linear mixed effects model extends the linear model to include random effects. If we start with a basic linear regression model with one predictor \(x\), we can define three versions: a random intercept model, a random slope model, and a full random model.

23.2.1.1 Random intercept model

This model has a random effect of group on the intercept. The first part is the response distribution that relates the expected value \(\mu_i\) to the observed values in \(y_i\).

\[y_i\sim\text{Normal}\left(\mu_i,\sigma^2_{res}\right)\]

The systematic part of the model, containing the expression for \(\mu_i\), includes an effect \(\gamma_{group_i}\) which is the effect on the intercept associated with the group of observation \(i\). The form below is the effects parameterization, which expresses the random effect as how it changes the intercept. In other words, the realized intercept in group A will be \(\beta_0+\gamma_A\)

\[\mu_i=\beta_0+\beta_1x_i+\gamma_{group_i};\text{ }\gamma_{group}\sim \text{Normal}\left(0,\sigma^2_{\gamma_{group}}\right)\]

The group-level effects on the intercept follow a normal distribution with mean \(0\) and variance \(\sigma^2_{\gamma_{group}}\).

Because the global intercept \(\beta_0\) and the random intercept are both scalars and occur as a sum in the model, many people omit the \(\gamma\) term (“gamma”) and simplify this to:

\[\mu_i=\beta_{0,group_i}+\beta_1x_i\]

\[\beta_{0,group}\sim \text{Normal}\left(\mu_{\beta_{0,group}},\sigma^2_{\beta_{0,group}}\right)\]

The first version keeps the global intercept and the group-level effect on the intercept separate, while the second version fits a group-level intercept directly.

23.2.1.2 Random intercept model

This model has a random effect of group on the slope It has the same response distribution step as the random intercept model above. The systematic part is a bit different: the random effect of group changes the slope of \(x\), not the intercept.

\[\mu_i=\beta_0+\left(\beta_1+\gamma_{group_i}\right)x_i\]

\[\gamma_{group}\sim\text{Normal}\left(\mu_{\gamma_{group}},\sigma^2_{\gamma_{group}}\right)\]

Just as with the random intercept model, the random slope model can be simplified so as to specify a group-level slope directly:

\[\mu_i=\beta_0+\beta_{1,group_i}x_i\]

\[\beta_{1,group}\sim\text{Normal}\left(\mu_{\beta_{1,group}},\sigma^2_{\beta_{1,group}}\right)\]

23.2.1.3 Random intercept and slope model

The full random model has a random intercept and a random slope. We get this model by combining the random intercept model and the random slope model:

\[\mu_i=\beta_{0,group_i}+\beta_{1,group_i}x_i\]

\[\beta_{0,group}\sim \text{Normal}\left(\mu_{\beta_{0,group}},\sigma^2_{\beta_{0,group}}\right)\]

\[\beta_{1,group}\sim\text{Normal}\left(\mu_{\beta_{1,group}},\sigma^2_{\beta_{1,group}}\right)\]

23.2.2 Example with NEON data

Let’s explore a linear mixed effects model using the NEON data. If you haven’t already, download the individual measurements dataset and the site metadata dataset.

dat <- read.csv("data-neon-ind-meas.csv")
met <- read.csv("data-neon-metadata-site.csv")

We are going to test for sexual dimorphism in body mass among white-footed mice (Peromyscus leucopus). We will also need to control for possible habitat differences.

Let’s filter and join the data first:

# filter to Perleu
dat <- dat[dat$abb=="Perleu",]
# drop missing body mass
dat <- dat[!is.na(dat$weight),]
# pull site out of tag id
dat$site <- sapply(strsplit(dat$tagID, "_"), "[", 2)

# only need these columns
use.cols <- c("site", "sex", "weight")
dx <- dat[,use.cols]

# merge to site descriptors
dx <- merge(dx, met, by="site")

# remove animals with unknown sex
dx <- dx[dx$sex %in% c("female", "male"),]

# remove wildly unrealistic body masses
dx <- dx[dx$weight >= 10 & dx$weight <= 30,]

We can check a boxplot of female vs. male body mass. It looks like any effect will be small.

boxplot(weight~sex, data=dx)

What about potential habitat differences? It makes sense that different habitats, like forests or grasslands or croplands, might have different levels of nutrient availability, or predation pressure, or something that might affect body mass.

# make a boxplot, but turn it horizontal
# and enlarge the y axis margin to make the
# habitat names visible
par(mar=c(4, 10, 1, 1), las=1)
boxplot(weight~habitat, data=dx,
        horizontal = TRUE,
        ylab="", xlab="Body mass (g)")

There is a lot of variability, but it looks like there might be some differences in body mass between the habitats.

We will fit the model two ways: as a linear model (two-way ANOVA) and as a linear mixed effects model.

One issue we might want to consider is that each habitat type is represented by several sites, and there might be variability between sites. For example, the “deciduousForest” habitat at GRSM might be different than the same category at HARV. GRSM is in the Great Smoky Mountains National Park in southeastern Tennessee, and HARV is Harvard Forest in Massachusetts. Both are dominated by deciduous forest, but they are not the same kind of deciduous forest. GRSM is in the Ridge and Valley and Southwestern Appalachian ecoregion, while HARV is in the Northeastern Coastal Zone.

We want to isolate the effect of habitat while accounting for other differences between the sites. We need to account for site-to-site variability, but recognize that we are not interested in these sites in and of themselves. The sites where “deciduous forest” and “grassland” were sampled are essentially a random sample of all the many possible places where they could have been sampled. That argues for treating site as a random effect.

It looks like we will get the most robust comparison if we restrict our analysis to deciduous forest and grassland habitats. Filter the dataset to those habitats.

# restrict to deciduous forest and grasslands
dx2 <- dx[dx$habitat %in% c("deciduousForest", "grasslandHerbaceous"),]

# remove site wood, which has only 1 animal
dx2 <- dx2[dx2$site != "WOOD",]

Now let’s run the analysis in two ways: as a linear model and as a linear mixed effects model. The linear model version of the analysis is a two-way ANOVA with habitat and sex plus the interaction between them. The mixed model version has the same fixed effects structure, plus a random intercept for site.

library(lme4)
library(lmerTest)

# two-way anova (linear model)
mod1 <- aov(weight~habitat*sex, data=dx2)

# mixed model with random intercept by site
mod2 <- lmer(weight~habitat*sex+(1|site), data=dx2)

    estimate = b,
    lower = b - 1.96 * se,
    upper = b + 1.96 * se

23.2.3 Specifying random effects in lme4

In lme4, the random effects are added to a model formula as terms after the fixed effects. Random effects are added in a form like (a|b), where a defines the model term that is a random effect, and b is the factor that defines the groups. 23.3 Generalized linear mixed effects models (GLMM)

Just as generalized linear model (GLM) extend linear models by allowing for non-normal response distributions, generalized linear mixed models (GLMM) extend linear mixed models in the same way. We will use package lme4 to fit GLMM.

23.3.1 Definition

The overall structure of a GLMM is similar to the structure of a GLM. The only difference is that while the only variance component of a GLM is in the response distribution (and thus relates to residual variation), GLMMs add additional structure to the variance by allowing model parameters to vary randomly.

The response variable \(y\) varies according to some distribution with expected value \(E\left(y\right)\) and sometimes additional parameters \(\theta\):

\[y\sim SomeDistribution\left(E\left(y\right),\theta\right)\]

The expected value on the data scale is related to the scale of the linear predictor \(\eta\) by a link function:

\[\text{LinkFunction}\left(E\left(y\right)\right)=\eta\]

And the linear predictor \(\eta\) is a linear function of the predictor variables (we’ll just use 1, \(x\), for now).

\[\eta=\beta_0+\beta_1 x\]

But, to make this a GLMM instead of a GLM, we let the model parameters vary according to levels of some factor (grouping variable) denoted by \(j\). For example, a GLM with a random intercept will have linear predictor

\[\eta=\beta_{0,j}+\beta_1 x\]

\[\beta_0\sim\mathcal{Normal}\left(\mu_{\beta_0},\sigma^2_{\beta_0}\right)\]

and a GLM with a random slope will look like

\[\eta=\beta_0+\beta_{1,j} x\]

\[\beta_1\sim\mathcal{Normal}\left(\mu_{\beta_1},\sigma^2_{\beta_1}\right)\]

And remember, as with LME, we can write the means (or coefficients) parameterization as above where \(\beta_0\) or \(\beta_1\) follow distributions, or we can write the effects (or deviation) parameterization where the global parameter is specified and we fit the variance of the random effects. For example:

\[\eta=\left(\beta_0+\gamma_j\right)+\beta_1 x\]

\[\gamma_j\sim\mathcal{Normal}\left(0,\sigma^2_{\beta_0}\right)\]

In the means parameterization, we fit \(\mu_{\beta_k}\) as the global intercept (or slope) and the variance \(\sigma^2_{\beta_k}\) to define the spread among the groups. In the effects parameterization, we fit the global intercept or slope (i.e., the fixed effect) as \(\beta_k\), and assume that group-level values vary according to a normal distribution with mean 0 and variance \(\sigma^2_{\beta_k}\). The effects parameterization is what R and lme4 present by default, but I find it more informative to write and discuss the model in means parameterization. Your mileage may vary.

To summarize: in the effects parameterization, we model how much each group differs from the population-level intercept; in the means parameterization, we model the group-specific intercepts directly. Both describe the same model, and we can translate between them by adding or subtracting the population-level intercept.

The difference between these two modes of specifying group-level parameters is shown in Table 23.2 below.

23.3.2 Example with NEON data

23.3.2.1 Data import and first steps

Let’s revisit the NEON small mammal capture data. Download the individual measurement dataset and the taxonomic dataset and put them in your working directory.

tax <- read.csv("data-neon-taxa.csv")
ind <- read.csv("data-neon-ind-meas.csv")

We are going to use mixed models to investigate sexual dimorphism in body mass in white-footed mice (Peromyscus leucopus). We investigated this previously in Section 23.2.2. This time, we are going to investigate how body mass varies with body length in males and females. We are going to use a Gaussian GLM with a log-link. The log-link is appropriate here because body mass is a strictly positive, continuous variable. However, we do not suspect overdispersion, so we don’t need a Gamma distribution. We will also test a random effect for site. We are interested in this random effect because different sites have different conditions that may affect body mass.

First, filter the data down to P. leucopus, with non-missing weights and lengths, with realistic masses and lengths, and with known sex.

# filter to species P. leucopus

At first glance, it appears that mass increases with total length (as it should). It’s hard to tell whether there is an effect of sex. We should suspect from Section 23.2.2 that there is at least a main effect of sex (different intercept).

It looks like there are some anomalous points in the upper left of the plots. Mice up there have very large mass relative to their body length. Let’s delete them and replot.

Much better. Those anomalous mice might be legitimate–for example, a mouse with an injured or missing tail would have a very large mass relative to its total length–but that would still warrant their removal.

23.3.2.3 Plotting population-level predictions

Let’s plot the model’s predicted values to see how male and female mouse mass varies with length.

# sex-specific sequences of x values
px1 <- seq(min(dx$loglen[dx$sex=="female"]),
           max(dx$loglen[dx$sex=="female"]), length=100)
px2 <- seq(min(dx$loglen[dx$sex=="male"]),
           max(dx$loglen[dx$sex=="male"]), length=100)

# sex-specific data frames
prx1 <- data.frame(loglen=px1, length=exp(px1), sex="female")
prx2 <- data.frame(loglen=px2, length=exp(px2), sex="male")

When we calculate predictions, we need to use the argument re.form to specify how predict() will account for the random effects. We will use re.form=NA, which gives us the population-level prediction with the random effects set to 0. In other words, this is the predicted value at the average random effect on the link scale. It does not represent a prediction averaged over the distribution of random effects across sites (i.e., the marginal mean). To obtain that, we must account for the estimated variance of the random effects. With an identity link function, these two predictions are the same. With a nonlinear link function such as the logarithmic link used here, the difference can be substantial, especially if the random-effect variance is large.

The take-home message is that re.form=NA is appropriate for illustrating the fixed-effect relationship, but we should be careful not to refer to these predictions as population-averaged means. In summary:

  • Population-level prediction with the random effects set to 0: Expected mass at a site with random intercept zero. Set re.form=NA.
  • Marginal means (population average): Expected mass averaged over the distribution of site random effects. Need to integrate over random effects (see example below).
# calculate population-level predictions
prx1$fit <- predict(mod05, newdata = prx1,
                    type = "response", re.form = NA)

prx2$fit <- predict(mod05, newdata = prx2,
                    type = "response", re.form = NA)

And plot:

par(mar=c(5,5,1,1))
plot(weight~totalLength, data=dx,
        pch=dx$pch, col=dx$col,
        ylab="Body mass (g)", log="xy",
        ylim=c(10, 50))
lines(prx1$length, prx1$fit, col=cols[1], lwd=3)
lines(prx2$length, prx2$fit, col=cols[2], lwd=3)
legend("right", legend=sexes,
       pch=pchs, col=cols, lwd=3)

Finally, let’s calculate and present the 95% confidence intervals. Unlike glm() and lm(), glmer() does not provide se.fit=TRUE in the usual way. There are two reasonable approaches.

For the population-level predictions, we can calculate the standard error of the linear predictor using the fixed-effect variance-covariance matrix, then transform the confidence limits back to grams.

get_ci <- function(mod, newdata) {

  newdata$sex <- factor(newdata$sex,
                        levels = levels(model.frame(mod)$sex))

  X <- model.matrix(
    delete.response(terms(mod, fixed.only = TRUE)),
    data = newdata
  )

  b <- fixef(mod)
  V <- as.matrix(vcov(mod))

  eta <- as.vector(X %*% b)
  se <- sqrt(rowSums((X %*% V) * X))

  newdata$fit.plm <- exp(eta)
  newdata$lwr.plm <- exp(eta - 1.96 * se)
  newdata$upr.plm <- exp(eta + 1.96 * se)

  newdata
}

prx3 <- rbind(prx1, prx2)
prx3 <- get_ci(mod05, prx3)

23.3.2.4 Plotting marginal means

If we want to see the marginal means, which are predictions that average over the distribution of sites, we need to integrate over the distribution of random effects. Note that the calculations below are specific to this model, a Gaussian GLM(M) with a log link. If you have a different response distribution or link function, the calculation is different.

v <- as.numeric(VarCorr(mod05)$site[1, 1])

prx1$fit.mm <- predict(mod05,
                       newdata = prx1,
                       type = "response", re.form = NA) *
    exp(v / 2)

prx2$fit.mm <- predict(mod05,
                       newdata = prx2,
                       type = "response", re.form = NA) *
    exp(v / 2)


par(mar=c(5,5,1,1))
plot(weight~totalLength, data=dx,
        pch=dx$pch, col=dx$col,
        ylab="Body mass (g)", log="xy",
        ylim=c(10, 50))
lines(prx1$length, prx1$fit.mm, col=cols[1], lwd=3)
lines(prx2$length, prx2$fit.mm, col=cols[2], lwd=3)
legend("topleft", legend=sexes,
       pch=pchs, col=cols, lwd=3, bty="n")

In this case, the marginal means and the population-level predictions are pretty similar. Note that the procedure above is appropriate for a Gaussian GLMM with a log-link. The integration is different for other GLMMs.

We can also plot the 95% CI of the marginal means, but it’s a little more involved. One way to estimate the CI is to use a parametric bootstrap using bootMER(). The code block below was not run during rendering because it takes over an hour.

pred_fun <- function(mod) {
  v <- as.numeric(VarCorr(mod)$site[1, 1])
  predict(mod, newdata = prx3,
          type = "response", re.form = NA) * exp(v / 2)
}

set.seed(123)

bt <- bootMer(mod05, FUN = pred_fun,
              nsim = 500, type = "parametric",
              use.u = FALSE)

prx3$fit.boot <- pred_fun(mod05)
prx3$lwr.boot <- apply(bt$t, 2, quantile,
                       0.025, na.rm = TRUE)
prx3$upr.boot <- apply(bt$t, 2, quantile,
                       0.975, na.rm = TRUE)

# then make the plot as usual
