Appendix A — Appendix A

This appendix contains information on the small mammal datasets used to construct many of the data analysis examples. The original datasets were downloaded from the National Ecological Observatory Network (NEON). Once downloaded, the data were filtered to exclude incomplete or possibly incorrect records, and to update taxonomy to 2026 conventions. The data were then reorganized into 4 tables:

  1. neon-grids.csv: contains metadata on trapping grids.
  2. neon-captures.csv: contains small mammal capture data.
  3. neon-measures.csv: contains small mammal body mass and standard measurements.
  4. neon-taxa.csv: contains taxonomic definitions for each species in the capture data.

A.1 Data dictionary

A.1.1 neon-grids.csv

  • domain: sampling region or domain as defined by NEON.
  • site: unique four letter code for site name.
  • grid: unique grid ID, nested within site.
  • lat: latitude in degrees north.
  • lon: longitude in degrees east.
  • elev: elevation in m.
  • nlcd: dominant NLCD land cover type within grid.

A.1.2 neon-captures.csv

  • grid: unique grid ID (corresponds to neon-grids$grid
  • AMHA through ZATR: number of captures of each small mammal species. Four-letter species abbreviations correspond to neon-taxa.csv, column abb.

A.3 Data download

The first step was to download all small mammal data from June 2013 through December 2023. The data used were finalized, non-provisional data. The data were downloaded and unzipped to a folder, top.dir.

## Unzipped the resulting download into 
top.dir <- "K:/_neon/NEON_count-small-mammals"

The data at this point were organized by folders, with each folder containing the data from a single site and trapping bout.

A.4 Read data into memory

# get folder names
folds <- dir(top.dir)

# only need the folders, which have "RELEASE-20" 
# in their names
folds <- folds[grep("RELEASE-20", folds)]
n.folds <- length(folds)

# which columns do we want from basic dataset?
use.cols1 <- c("domainID", "siteID", "plotID",
              "decimalLatitude",
              "decimalLongitude", "elevation",
              "nlcdClass", "tagID",
              "scientificName", "sex", "lifeStage",
              "pregnancyStatus", "hindfootLength",
              "earLength",
              "tailLength", "totalLength", "weight",
              "tickNumber")  

# mlist for measured specimens
# spplist for species at each location
#   (includes extra species not in basic dataset)
spplist <- mlist <- vector("list", length=n.folds)
i <- 1

for(i in 1:n.folds){
  ifold <- paste(top.dir, folds[i], sep="/")
  ifile <- dir(ifold)
  
  # basic file--has individual captures
  ifile <- ifile[grep("_pertrapnight", ifile)]
  ix <- read.csv(paste(ifold, ifile, sep="/"))
  
  # only need captures
  ix <- ix[which(ix$trapStatus == "5 - capture"),]
  ispp <- character(0)
  
  # get basic captures, if any
  if(nrow(ix) > 0){
    ix <- ix[,use.cols1]
    mlist[[i]] <- ix
    # vector of species
    ispp <- sort(unique(ix$scientificName))
  }

  # get vouchers, if any
  # voucher file doesn't have any measurement data,
  # so just inspect to get unique species
  vfile <- dir(ifold)
  vfile <- vfile[grep("_voucher", vfile)]
  if(length(vfile) > 0){
    vx <- read.csv(paste(ifold, vfile, sep="/"))
    if(nrow(vx) > 0){
      # unique species in vouchers ## will have to remove nonmammals
      vspp <- sort(unique(vx$scientificName))  
      if(length(vspp) > 0){
        # combine with species in basic data
        ispp <- sort(union(ispp, vspp))  
      }#if any vspp
    }# if any rows in vx
    rm(vx)
  }#if vfile exists

  # save species to species list
  spplist[[i]] <- ispp
 
  rm(ix)
  rm(ispp)
  
  cat("folder", i, "of", n.folds, "done!\n")
  flush.console()
}
